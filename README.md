## Возможности

| Раздел | Что доступно |
| :--- | :--- |
| **Подписки** | Импорт по ссылке, из файла, QR-кода и буфера обмена. Автообновление и HWID. |
| **Маршрутизация** | VPN для выбранных приложений, правила доменов и IP, локальная сеть и фрагментирование Xray. |
| **Пинг** | Проверка одного сервера или всего списка. HTTP GET/HEAD, TCP, TLS, DNS, ICMP и KeepAlive для HTTP. |
| **Подключение** | VPN, VPN + прокси или только прокси. Автозапуск, общий прокси для Wi-Fi с паролем и управление из шторки. |
| **Туннель** | Выбор ядра, IP, DNS и MTU, Mux для совместимых профилей Xray и работа при погашенном экране. |
| **Оформление** | Светлая, тёмная, AMOLED и Material You. Свой цвет блоков и анимированный фон. |
| **Языки** | Русский и английский. |

**Протоколы:** VLESS, VMess, Trojan, Shadowsocks, Hysteria, Hysteria2 и TUIC.

Короткий свайп открывает кнопку пинга или удаления. Действие выполняется только по нажатию.

Kill Switch удерживает туннель при сбое ядра. Защита действует, пока приложение продолжает работать.

## Установка

Открой [последний релиз](https://github.com/GODIS00/NyaWire/releases/latest) и выбери APK:

| Файл | Для каких устройств |
| :--- | :--- |
| **arm64.apk** | Большинство современных телефонов |
| **universal.apk** | Остальные архитектуры и эмуляторы |

После установки добавь свою подписку или сервер.

## Обновления

При открытии NyaWire проверяет новые версии на GitHub и предлагает скачать APK.
Вручную: **Настройки → О приложении → Проверить обновления**.
