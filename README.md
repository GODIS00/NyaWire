# GDHAPP

VPN-клиент для Android 10+ на Xray и sing-box.

[Скачать](https://github.com/GODIS00/GDHAPP/releases/latest)

- **arm64.apk** — для большинства телефонов.
- **universal.apk** — для остальных устройств.

Установи APK поверх старой версии. Подписки и настройки сохранятся.

## Обновления

С версии 2.8.1 приложение само проверяет новые версии.
Вручную: **Настройки → О приложении → Проверить обновления**.
